- Goal: get a working `node`, `npm` and npm registry.
- Files: none.

  4. Stop if `node` is missing or the code is not 200.
  5. Tell bcollet which part failed. Give him the command to run with the `!`
     prefix.
- Verification: run `node --version` and `npm ping`.
- Done when: `node --version` prints a version, and `npm ping` succeeds. Or
  bcollet confirms that he runs every npm command himself.
